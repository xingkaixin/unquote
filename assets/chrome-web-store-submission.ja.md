## 1. ストア掲載情報

### 名前

Unquote - エスケープ JSON 展開・JSONL ビューア

名前は拡張機能パッケージ内の日本語マニフェストリソースから取得されます。変更する
場合は、デベロッパーダッシュボードだけでなく
`apps/extension/public/_locales/ja/messages.json` も更新してください。

### 概要

文字列化された JSON を展開し、JSONL をローカルで閲覧できます。

この概要はマニフェストの `description` と同じ内容です。

### 詳細な説明

Unquote は、ブラウザ内で動作する JSON / JSONL ビューアです。文字列値の中に
エンコードされた JSON を検出して再帰的に展開し、読みやすいインタラクティブな
ツリーとして表示します。API レスポンス、ログ、AI モデルの出力、エージェントの
ツール呼び出し記録の確認に適しています。

主な機能：

- JSON と JSONL を自動判別し、文字列化された JSON を再帰的に展開
- ネストしたデータをツリー、パス、型、シンタックスハイライトで確認
- キー、値、JSONPath をレコード横断で検索
- JSONL の成功、失敗、ネストしたパス、フィールド概要を表示
- Codex と Claude Code のログを認識し、会話、ツール呼び出し、タイムラインを表示
- 処理後の JSON / JSONL をコピーまたはエクスポート
- ローカルファイルを開くかドロップし、ウェブページで選択した JSON を右クリックメニューから送信
- ライト、ダーク、システムテーマに対応
- ユーザーのデータを外部へ送信せず、すべてローカルで処理

Unquote はアカウント不要で、広告や閲覧行動の追跡もありません。

## 3. プライバシーに関する申告

### 単一目的

ユーザーが明示的に提供した JSON、JSONL、エージェントログを端末内で解析、展開、
検索、表示します。

### 権限の説明

#### `contextMenus`

テキスト選択時の右クリックメニューに「Unquote で開く」を追加します。ユーザーが
この項目を選んだ場合に限り、選択されたテキストを Unquote で開きます。ページの
内容を自動的に読み取ることはありません。

#### `storage`

ユーザーが選択したテキストを新しい Unquote ページへ渡すため、
`chrome.storage.session` を使用します。データは現在のブラウザセッションに最長
5 分間だけ保持され、最初に読み取られた直後に削除されます。プロファイル作成や
端末間同期には使用しません。

#### `clipboardRead`

ユーザーが貼り付け操作を行い、クリップボードの内容が JSON / JSONL ファイルを
表す場合に限り読み取ります。バックグラウンドでの読み取り、ポーリング、監視は
行いません。

### ホスト権限

ホスト権限は要求しません。任意のウェブページ、閲覧履歴、Cookie、ネットワーク
通信を読み取ることはできません。

### リモートコード

次を選択します。

> いいえ、リモートコードは使用していません。

説明：

> 拡張機能の JavaScript と WebAssembly（使用する場合）はすべてパッケージ内に
> 含まれています。外部でホストされたコードをダウンロード、読み込み、実行する
> ことはありません。

### データ使用の開示

拡張機能は、ユーザーが明示的に提供した次のデータを端末内で処理します。

- ユーザー生成コンテンツ：入力、貼り付け、ファイル選択、ドロップされた JSON / JSONL
- ウェブサイトのコンテンツ：ユーザーが選択し「Unquote で開く」で送信したテキストのみ

処理方法：

- データは拡張機能ページとセッションストレージ内でのみ処理
- デベロッパーまたは第三者のサーバーへ送信しない
- 広告、分析、信用評価、パーソナライズなど、公開された単一目的以外には使用しない
- 販売、共有、人による閲覧を行わない
- ローカルファイルは通常ページのメモリにだけ保持
- 右クリックメニューのデータは最長 5 分で削除し、最初の読み取り後にも即時削除
- テーマと言語の設定のみブラウザのローカルストレージに保存する場合がある
- コピーとエクスポートはユーザーが明示的に実行した場合のみ行う

データが端末外へ送信されない場合でも、ユーザー提供データを処理するため、
「ユーザーデータを一切処理しない」は選択しません。

### Limited Use の確認

次の項目を確認できます。

- データ処理は公開された単一目的に限定
- ユーザーデータを第三者へ販売または転送しない
- 単一目的と無関係な用途に使用しない
- 信用評価や融資に使用しない
- 人による閲覧を許可しない

## 4. プライバシーポリシー案

公開済みの HTTPS ページをデベロッパーダッシュボードに登録してください。推奨 URL
は `https://unquote.xingkaixin.me/privacy` です。ページが実際に公開される前に
この URL を提出しないでください。

### Unquote プライバシーポリシー

発効日：2026 年 7 月 24 日

Unquote は、ユーザーの端末上で JSON、JSONL、エージェントログを解析して表示する
ブラウザ拡張機能です。

#### 取り扱うデータ

ユーザーが明示的に入力、貼り付け、選択、ドロップ、または右クリックメニューから
送信した内容だけを扱います。テーマと言語の設定を端末内に保存する場合があります。

#### 利用目的

ユーザーの端末上で JSON / JSONL を解析、展開、検索、表示、コピー、エクスポート
するためだけに使用します。広告、分析、プロファイリングなどには使用しません。

#### 保存と保持期間

解析した内容は通常、現在の拡張機能ページのメモリにだけ保持されます。右クリック
メニューから送信されたテキストは Chrome のセッションストレージで最長 5 分間
保持され、最初の読み取り直後に削除されます。テーマと言語の設定は、ユーザーが
拡張機能データを削除するまで端末内に残る場合があります。

#### 転送と共有

ユーザー提供データをデベロッパーまたは第三者のサーバーへ送信せず、販売、共有、
人による閲覧も行いません。

#### 権限

右クリックメニュー、ページ間の一時的なセッションストレージ、ユーザー操作による
JSON / JSONL ファイルの貼り付けに必要なクリップボード読み取りだけを使用します。
ウェブサイトのホスト権限は要求しません。

#### ユーザーによる管理

入力のクリア、ページを閉じる、拡張機能データの削除、アンインストールによって
ローカルデータを削除できます。コピーとエクスポートは明示的な操作でのみ実行します。

#### ポリシーの変更

データの取り扱い方法を変更する場合は、このポリシーを更新し、Chrome ウェブストア
の要件に従って必要な通知を行います。

#### お問い合わせ

質問やプライバシーに関する依頼は、次のページから送信してください。
`https://github.com/xingkaixin/unquote/issues`

Unquote による情報の利用は、Limited Use 要件を含む Chrome ウェブストアの
ユーザーデータポリシーに準拠します。

## 5. 審査担当者向けメモ

> Unquote はログインやテストアカウントを必要としません。拡張機能アイコンを
> クリックしてメインページを開き、入力欄の下にあるサンプルを使用してください。
> 「エスケープされた API レスポンス」で再帰展開、「Codex ロールアウト JSONL」で
> エージェントセッション、「有効・無効混在の JSONL」で行ごとのエラー診断を確認
> できます。ホスト権限は要求せず、すべてローカルで処理します。

右クリックメニューの確認：

1. 任意のウェブページで JSON テキストを選択します。
2. 右クリックして「Unquote で開く」を選択します。
3. 新しい拡張機能ページに選択した内容が表示されます。

キーボードショートカット：

- Windows / Linux：`Ctrl+Shift+U`
- macOS：`Command+Shift+U`
